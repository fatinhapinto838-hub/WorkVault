# WorkVault 中文用户手册

## 第一次使用

打开应用，按引导选择永久文件库，下载监控和 AI 都可以跳过。首页数字来自本地 SQLite。未导入时显示真实空状态，不包含演示项目。

## 导入成果

1. 点击右上角“导入文件”。选择单个或多个文件，或选择整个目录；也可以把文件/目录拖到界面。网页上传按钮支持浏览器文件选择。
2. 选择已有项目，或先“新建项目”，粘贴 Work 原始标题、可用会话 ID 和来源链接。缺少 ID 的同名任务是不同项目。
3. 确认确为 Work 成果时勾选来源确认；不确定就保留待确认。
4. 开始导入，查看进度。大文件原生导入流式复制，不删除原文件。可取消剩余任务，失败可重试。
5. 收件箱批量确认来源、关联项目或移入本地回收站。未知下载不自动变成正式 Work 档案。

完整相同的内容只存一份 blob，可关联多个项目。同名但内容不同创建独立记录；需要新版本时在文件详情明确“上传新版本”。ZIP 导入安全检查后保留压缩包并展开一层子文件，不递归展开嵌套压缩包。

## 自动接收与真实任务标题

同步中心添加专用 WorkVault-Inbox 或 Downloads 路径，明确授权后开启。扫描等待文件大小和修改时间稳定，不修改来源文件；Downloads 原有文件建立基线，后续新文件待确认。可暂停/删除来源。

可对有本地文件访问能力的 Work 明确说：“将最终成果保存到我授权的 WorkVault-Inbox 目录。”这不是云端任务的全量自动同步。若需要标题自动关联，可同时让任务写入 `.workvault.json` 显式清单，示例见 `docs/WORK_TITLE_MANIFEST.md`。单凭文件名不会声称获得真实标题。

历史导入：先通过 ChatGPT 官方设置导出数据，下载 ZIP。WorkVault 的历史导入入口选择 ZIP、包含 conversations JSON 的目录或 JSON。解析真实字段，显示可识别标题和会话 ID；未知 Work/Chat 类型保持待确认。不存在的附件仅登记“需要补充原文件”。不要把普通聊天一键都认作 Work。

## 项目管理

项目中心按主题和状态筛选。详情保留原始标题、显示标题、来源、链接、描述、标签、时间线和最终成果。手动修改显示标题不会被后续导出标题覆盖。可以关联多文件、合并项目或选文件拆分项目；可靠 ID 优先，同标题不自动合并。

## 文件浏览、预览、编辑、版本

文件中心支持全局搜索（⌘K）、项目/格式/收藏筛选、排序、分页、列表/网格、多选、右键操作、标签和详情。⌘I 打开导入，Escape 关闭弹窗。

PDF 和常见图片可在本机浏览器引擎预览；文本、Markdown、代码、CSV 以安全简化方式展示。Office 展示本地 XML 提取内容，**不是保真排版**；XLSX 可能显示共享字符串/单元格原始值，PPTX 不保证幻灯片视觉布局。需要原版时“默认应用打开”。不使用在线转换服务。扫描 PDF 无文字时明确说明；当前未集成 OCR。

“默认应用打开”创建受管理可编辑工作副本，原始 blob 和历史版本不直接改写。编辑并保存后点“检查外部编辑”，选择登记为新版本或放弃工作副本。检查是用户主动触发，**当前没有每秒自动扫描工作副本**。上传新版本与恢复旧版本都保留历史；恢复操作新增版本。可标记最终版本与多个最终成果。

“Finder 定位”显示受保护文件实体，其名称可能是哈希；要分享正常文件名，使用“导出”。删除只进入 WorkVault 回收站，可恢复；不会删除 ChatGPT 远程会话或原下载。

## AI

见 AI_CONFIGURATION.md。没装 Ollama 或没填 Key 时基础管理完全可用。先手动建立索引或选定文件分析，选择本地或 DeepSeek，检查实际片段并确认。DeepSeek 还需要每个涉及项目单独授权、配置价格和预算。

## 备份、恢复、迁移

只手动备份，见 BACKUP_AND_RESTORE.md。恢复到独立新目录，校验后再选择已有文件库。迁移保持旧目录，见 DATA_MIGRATION.md。不要在外部应用直接编辑 SQLite 或 blobs。

## 资源与退出

设置可看本机进程资源、日志、监控状态。AI 单并发按需请求，可以取消；取消不代表已被第三方接收的数据撤回。退出会停止本应用 HTTP 服务、扫描计时器和请求，不停止用户另行启动的 Ollama。


## 最终成果栏目

左侧「最终成果」按项目集中展示交付文件；项目详情也有入口。「添加成果」选择已确认的项目文件，版本历史可选旧版本。后续编辑不会改变已收录版本；「移出」只取消收录，不删除文件。详见 [完整说明](FINAL_DELIVERABLES.md)。
