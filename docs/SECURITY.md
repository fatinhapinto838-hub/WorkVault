# 安全与隐私

- 文件、数据库、预览和索引保存在本地用户选定目录。基础管理不联网。
- 仅监听 127.0.0.1 的随机 TCP 端口。每次启动新随机会话；入口 token 换 cookie 后清除地址栏参数。请勿把带 token 的启动链接分享给他人。
- 写 RPC 只接受 application/json，检查精确 Origin（存在时）与 Host；不返回 CORS 许可。浏览器会话 HttpOnly、SameSite=Strict。CSP 限制脚本、请求与嵌入源。
- 静态资源使用固定允许列表。内容端点只根据数据库 ID 定位 blob，HTML/SVG/脚本不会作为可执行页面预览。文件以 nosniff 与受限类型发送。
- 网页上传有 2 GiB 上限并写入 0600 临时文件，原生导入分块复制。JSON 2 MiB，请求头 16 KiB，连接上限与超时避免无界积累。
- 本地同账户进程本来可以读取用户文件；本应用不是防御恶意本机进程的沙箱。原生选择器和显式路径导入由当前授权会话操作，不构成对远程网站的文件访问 API。
- 不收集 ChatGPT cookie/token/密码，不读其私有数据库，不解析私有通讯协议，不访问浏览器配置和密码库，不申请辅助功能或屏幕录制。
- Keychain 仅访问 WorkVault 自身的 DeepSeek 服务项；不在日志、设置 JSON、备份保存明文 Key。卸载默认保留库和密钥，用户可先在设置删除自己的 API Key。
- DeepSeek 默认禁用。只有涉及项目全部授权、预览确认且预算检查通过才发送选定片段至官方 HTTPS 端点。授权撤销阻止后续请求，不表示第三方已删除历史内容。
- Ollama 限本机服务且拒绝 cloud 标记模型。用户应自行确认 Ollama 配置和安装模型实际为本地运行；WorkVault 不下载模型。
- 压缩导入限制成员数量、展开大小/压缩比并拒绝绝对路径、路径穿越、符号链接。损坏压缩包报错，源文件不改动。
- 备份与迁移验证哈希，恢复只写空的新目录，保留当前库。日志不保存 AI 完整敏感请求正文。
- 默认不开机启动、不自动备份、不启用 Downloads、不扫描未选择目录、不自动 AI 分析。系统级 Gatekeeper/SIP 无需关闭。

本机 ad-hoc 签名只用于本机构建完整性，不是 Apple Developer 身份签名或公证。尚未进行第三方安全审计，报告中列出的测试不能等同于形式化安全证明。
