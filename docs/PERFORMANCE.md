# 实际性能基准报告

测试日期：2026-11-17。平台：macOS 15.8.3（24H241），Apple Silicon ARM64；Apple Swift 6.1.2，`-O` 优化。原始结果：`Tests/results/benchmark-results.json`。

## 方法与边界

使用 `Tests/Benchmark.swift` 直接调用生产 `Store.rpc`，包括 SQL 查询、计数、分页及每条文件的项目/来源等元数据组装。每项先预热 1 次，再测量 31 次；时间来自单调时钟，记录中位数与 p95。测试完全在工作区随机隔离目录进行，结束后删除；没有将合成记录放入正式界面或用户文件库。

每组包含 50 个项目及 1,000 / 5,000 / 10,000 个规范文件/版本/项目关系/来源/检索元数据记录。所有记录引用同一个经真实导入和 SHA-256 校验的小型文件实体，以隔离查询性能；数据库外键及文件完整性检查通过。批量种入元数据使用事务。

**这些是已预热的进程内元数据查询结果，不包括 HTTP、WKWebView、JavaScript 渲染、冷启动、大文件复制、10000 个独立实体的磁盘吞吐、OCR、全文向量索引或真实模型推理。** 查询只读数据库，没有逐次扫描磁盘文件。因只有一个共享实体，不应将磁盘容量数据用于估计真实成果文件库。

## 数据准备与资源

| 记录数 | 事务种入耗时（ms） | 进程累计峰值 RSS（MiB） | SQLite＋WAL（MiB） |
|---|---:|---:|---:|
| 1,000 | 40.1 | 11.2 | 2.94 |
| 5,000 | 197.7 | 18.0 | 12.46 |
| 10,000 | 396.3 | 25.2 | 22.85 |

RSS 来自 macOS `getrusage(RUSAGE_SELF).ru_maxrss`，单位按 macOS 为字节，表示同一基准进程至该组结束的累计峰值；不含原生应用窗口/WebKit 子进程，也不是空闲状态内存。种入时间不是用户文件导入速度。

10,000 条规模下，本次最慢查询项的 p95 为 18.456 ms。此结果支持当前分页及数据库查询在该合成规模下继续用于主流程，不代表已测所有硬件、文件布局或后台任务组合。

## 复现

开发机安装 Xcode Command Line Tools 后，在源码目录运行：

```sh
python3 Tests/benchmark.py
```

脚本仅创建隔离基准数据，编译结果在 `.build/`，报告写到 `Tests/results/benchmark-results.json`。若本机 CLT 存在重复 SwiftBridging map，使用只对编译器生效的 VFS overlay，不修改系统文件。正式用户启动应用无需 Python 或编译器。

下一阶段应补测：冷缓存/冷启动、真实多种大文件导入吞吐、监控目录变更率、WKWebView 渲染、万条长文索引及本机模型。
