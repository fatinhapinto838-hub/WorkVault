# WorkVault internal RPC contract (v1)
Native Swift ARM64 app + Network HTTP on 127.0.0.1 + WKWebView. No runtime installation. Web UI uses TypeScript (strict checked build where compiler available) compiled to plain JS. SQLite/FTS5; native SHA256, Keychain, PDFKit and ZIP tools. No external source changes.

POST /api/rpc JSON {action: string,...fields}. Returns JSON object directly (no data envelope), errors HTTP 400 {error:string}. Authentication: session cookie HttpOnly SameSite=Strict established by /?token=...; Host/Origin exact loopback validation; JSON content-type required. Native UI same endpoint. GET /content/{fileID}?version=ID for read-only blob content. Native dialog RPC chooses files/folders. Browser upload POST /api/upload?name=...&project_id=... streams raw bytes to temporary path, returns normal import response. GET /health public contains only status/version. Token never returned by RPC. Native dialog actions cancel returns {cancelled:true}.

All IDs strings UUID, time ISO8601; snake_case JSON keys. Tables/SQL exposed via Store.db methods query(sql,[Any?])->[[String:Any]], exec(sql,[Any?]); Store.root URL. Store.lock NSRecursiveLock; RPC core serialized except AI/background tasks. Store init(root:URL), func rpc(_ p:[String:Any]) throws -> [String:Any]; func blobURL(fileID:String,versionID:String?) throws -> URL; func importFile(path:String,name:String?,projectID:String?,source:String,confirmed:Bool) throws -> [String:Any]. Store.externalRPC optional closure installed by main handles unknown actions (AI + backup).

Actions:
- status -> {version,root,setup_complete,projects,files,inbox,bytes,free_bytes,recent_files:[File],formats:[{ext,count}],logs:[Log],storage_available}
- setup {root?,inbox_path?,downloads_path?} -> status (native choose_directory -> {path}; choose_files {directory?:bool,multiple?:bool} -> {paths:[...]})
- projects -> {items:[Project]}; project_save {id?,title,original_title?,title_source?,conversation_id?,source_url?,category?,description?,status?,tags?} -> {project:Project}; project_detail {id} -> {project,files,events}; project_merge {from_id,to_id}; project_split {id,title,file_ids}; project_delete {id} only removes empty project.
Project {id,title,original_title,title_source,title_obtained_at,conversation_id,source_url,category,description,status,created_at,updated_at,file_count,tags,deepseek_allowed}.
- files {q?,project_id?,status?:managed|pending|trash,ext?,favorite?:bool,tag?,sort?:name|newest|oldest|size,limit?:int,offset?:int} -> {items:[File],total}
File {id,name,ext,size,hash,status,favorite,final,tags,created_at,updated_at,project_ids:[String],source,source_path,confidence,current_version,index_status?}.
- file_detail {id} -> {file,versions:[Version],provenance:[...],projects:[...]}; file_update {ids:[String],name?,favorite?,final?,tags?,status?,project_id?,replace_projects?:bool}; trash restore via status.
- import {paths:[String],project_id?,confirmed?:bool,source?:manual|dedicated|downloads|history,job_id?} -> {imported,duplicates,failed,results:[...],job_id}; import_cancel {job_id}; import_jobs -> {items}; import_retry {id}; import_export {path} -> {projects,missing_files,warnings} (official export only structural parse; work unknown pending)
- preview {id,version_id?} -> {kind:text|image|pdf|office|unsupported,text?,html?,note?,url?}; open_file {id,version_id?} opens managed working copy for edit; reveal_file {id}; export_file {id,destination?}; check_edits -> {items:[{id,path,changed}]}; commit_edit {id,note?}; discard_edit {id}; version_add {id,path,note?}; version_restore {id,version_id}; version_final {id,version_id}.
Version {id,file_id,hash,size,created_at,source,note,is_current,is_final}.
- sources -> {items:[Source],logs:[...]}; source_save {id?,path,kind:dedicated|downloads,enabled:bool} -> {source}; source_delete {id}; scan -> {discovered,errors}; categories -> {items:[{id,name,position}]}; category_save {id?,name,position?}; category_delete {id}.
Source {id,path,kind,enabled,last_scan,error}. Poll at low cadence authorized directories only, stable two scans before import, ignore temporary/symlinks.
- settings -> {settings:{...},root}; settings_save {values:{...}} (AI params generic keys); logs -> {items}; integrity -> {checked,errors}; resources -> real PID/memory/process stats.
- backup_create {destination,include_index?:bool} -> {path,files}; backup_inspect {path} -> {valid,summary,errors}; backup_restore {path,destination,confirmed:true} -> {path,...} isolated new destination never overwrite current; migrate {destination} -> {root} keep old. Native choose_directory for paths. Backup no secrets, SHA manifest, db consistent snapshot.
- ai_status -> {ollama_available,models:[String],key_configured,indexed_chunks,requests:[...]}; ai_key {key} macOS Keychain only; ai_authorize {project_id,allowed:bool}; ai_index {file_ids?:[String],project_id?,embeddings?:bool} -> {job_id}; ai_job {job_id} -> {status,progress,error?,result?}; ai_cancel {job_id}; ai_delete_index {file_ids?,project_id?}; ai_search {q,semantic?:bool,project_id?} -> {items:[{file_id,file_name,project_title,locator,text,score}]}; ai_prepare {file_ids?,project_id?,prompt?,provider:ollama|deepseek,mode?} -> {preview_id,files,characters,excerpt,endpoint,estimated_cost}; ai_run {preview_id,confirmed:true} -> {job_id}. Modes summary/project_summary/tags/topic/qa/compare/related all prompt based. No automatic extraction/index/AI. AIEngine initialized with Store, func rpc(_ p) throws -> [String:Any]? nil if unknown. AI settings keys ollama_url (loopback only), ollama_model, embedding_model, deepseek_url (HTTPS api.deepseek.com only unless explicitly user override disallowed v1), deepseek_model, ai_max_chars, ai_max_tokens, ai_timeout, price_input,price_output,budget_request,budget_day,budget_month. Prices unset -> DeepSeek blocked until configured. All projects involved must allow cloud. Prepared preview immutable bounded content, authorization rechecked at dispatch; cancelled network tasks. Embeddings local only; exclude cloud-tagged Ollama models.
