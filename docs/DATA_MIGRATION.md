# 存储目录迁移与文件库切换

设置显示当前永久存储位置。修改位置请用“迁移文件库”，不要拖动正在使用的 blobs 或 SQLite 文件。

1. 先完成/取消导入和 AI 任务，登记重要工作副本编辑。
2. 选择新的空目录（不能位于当前库内，也不能包含当前库）。
3. 应用检查可写性和剩余空间，用 SQLite 快照复制元数据，复制 blob、必要工作副本及本地索引，并逐项验证 SHA-256、外键和当前版本引用。
4. 全部验证通过才切换 root，保留旧文件库。正常 GUI 模式将新位置存入应用偏好设置，下次启动继续使用。
5. 失败时旧库保留可用。目标目录可能留有已经复制的完整条目或锁文件，切勿把不完整目标当作成功迁移库；查看错误后选新的空目录重试。

已经有完整文件库（例如恢复备份）时用“选择已有文件库”，此操作验证数据库版本、外键与实体后切换，不将原库合并或覆盖。不同文件库不能同时被两个 WorkVault 进程写入，应用使用文件锁。

外置 SSD 断开时显示存储不可用，不把离线记录判为删除。请重新连接磁盘后重试；不要在断盘时点重建空库。当前没有对所有外置文件系统、休眠恢复和突然断电进行实机测试，重要迁移前先做独立备份。

程序更新只替换 .app，用户文件库留在自选目录。schema_migrations 记录迁移；较新结构需相应新程序支持，禁止直接使用旧版本写入。
