# AI 配置与使用

WorkVault 的导入、监控、去重和普通搜索不调用 AI，也不自动提取正文。所有索引、嵌入、摘要和问答均由用户单独发起。未安装 Ollama、未配置 API Key 时，基础功能仍可使用。

## 本地 Ollama

1. 自行从 [Ollama 官方网站](https://ollama.com/) 安装 Ollama，并选择适合本机的模型。WorkVault 不自动下载模型，不启动系统服务。
2. 在设置填写 `http://127.0.0.1:11434` 及已安装的推理模型名称。状态页请求 `/api/tags` 检查本地服务，真实请求前另请求 `/api/show` 检查模型。
3. 不接受非回环地址，也不接受名称包含 cloud、带 remote_model/remote_host 的模型。仅连接本地服务并不保证第三方服务本身永远不联网；应使用可信 Ollama 安装，并选择本地权重。
4. 需要语义检索时，另行配置一个已安装的本地嵌入模型。先手动为选中文件或项目建立索引，再勾选建立本地嵌入。
5. 纯文本索引不需要模型；语义索引通过本地 `/api/embed` 生成向量，存入本地 SQLite。FTS5 trigram 与余弦分数组合检索。普通文件名搜索与正文索引搜索相互独立。

16GB M3 建议先使用小型量化模型并关闭其他大型推理程序。此交付未自动安装模型，未声称在当前机器完成本地真实模型推理。嵌入请求与生成请求使用 `keep_alive: "0s"`，请求结束后要求 Ollama 卸载模型；这不会终止用户自行运行的 Ollama 服务。

## DeepSeek

1. 从 [DeepSeek 官方控制台](https://platform.deepseek.com/) 获取自己的 API Key。无需 ChatGPT 密码或 Plus 凭据。
2. 在设置保存 Key，凭据写入 macOS Keychain，普通配置、日志和备份不包含明文 Key。可通过保存空 Key 删除。
3. 默认官方地址为 `https://api.deepseek.com`，也允许其 `/v1` 路径。此版本拒绝其他域名和 HTTP，拒绝 HTTP 重定向。模型名称可配置；2026-11-17 官方示例使用 `deepseek-flash`，使用时应重新核对模型与价格。
4. 填写模型的输入和输出每百万 Token 价格，以及同币种单次/每日/每月预算（日期按 UTC 统计）。未填写价格或预算时，云端请求被阻止。成本是估算，不是账单。输入上限使用 UTF-8 字节数加提示词开销保守预留；输出按最大输出 Token 预留。成功且返回完整有效用量后用实际 Token 数更新估算；缺失/异常用量时保留预留金额并提示核对账单。失败、取消请求可能已经被计费，因此保留预留金额，避免低估预算。
5. 每个项目的 DeepSeek 授权默认关闭；一个文件关联多个项目时，所有相关项目均须允许云端处理。未关联项目的文件禁止云端处理。
6. 主动生成正文预览，核对文件、段落、地址、字符量、模型和估算成本，再确认发送。预览 30 分钟后过期；文件版本或项目关系发生变化后需重新预览。
7. 请求入队时和发出前重新检查授权。撤销授权会取消本应用 AI 任务并使相关预览失效；不代表 DeepSeek 删除此前已接收的数据。

**DeepSeek 会接收预览中的必要正文和用户问题，并可能产生费用。原始文件和索引仍在本机，但这不等于数据完全不出本机。**

## 使用与限制

- 文件/项目摘要、主题分析、标签建议、比较、相关性分析和项目总结使用选中文件的有界正文提取；问答先从所选文件的当前版本手动索引检索相关片段（可主动选择本地语义检索），再构建上下文。没有匹配索引时明确拒绝并提示手动建立/重建，不会自动全文索引。两者均使用同一预览确认流程。AI 建议不会自动覆盖标签或项目元数据。
- 本地正文预览仅要求填写模型名称，不会加载模型；真正点击发送后才检查模型是否已经安装且为本地权重。未安装模型时请求失败，并不会伪造回答。
- 同时最多执行一个 AI 任务，总排队上限 8 个任务（含运行项）；可取消。没有自动失败重试，以避免重复发送和重复费用。可由用户检查后重新发起。
- 单次最多选择 200 个文件；每个文件手动索引最多提取 200,000 字符。请求正文字符数、输出 Token 和超时均有上限。超限部分明确列出警告。
- PDF 引用显示实际提取页码。普通文本和简化 Office 提取使用提取正文位置与字符范围，不伪造原文件页码、工作表或章节。扫描 PDF、加密 PDF 和无可提取正文的格式明确失败；此版本未提供 OCR。
- 语义检索最多评估 20,000 个匹配模型向量候选；请在大型文件库按项目检索。使用过期版本的索引自动从结果排除，需用户手动重建。
- AI 返回的引用仍需要核对原文。全文截断、简化提取或资料不足时，不代表整个文件已被完整分析。
- 启动应用不加载模型；退出应用取消当前请求，应用不结束用户自行启动的 Ollama 进程。

官方协议来源（核验日：2026-11-17）：[Ollama API](https://docs.ollama.com/api/introduction)、[模型列表](https://docs.ollama.com/api/tags)、[嵌入](https://docs.ollama.com/api/embed)、[DeepSeek 首次调用](https://api-docs.deepseek.com/)。
