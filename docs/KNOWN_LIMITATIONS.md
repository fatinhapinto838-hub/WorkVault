# 已知限制与未实测范围

本文件列出实际限制，不以“全部完成”覆盖缺失能力。

1. **个人 ChatGPT Work 全量账户自动同步不可用。** 未找到适用于普通个人第三方应用的正式任务/标题/文件事件接口；不抓取凭据或私有数据库。当前助手工具可列标题不等于独立 .app 拥有公共 API。
2. 标题来自官方导出、用户输入/链接/ID、显式本地 `.workvault.json`。没有 ID 的同名任务不自动合并。官方导出中无法区分 Work/Chat 的项目是待确认，不计入已确认项目数。
3. 未提供用户真实官方导出包，解析器用已知结构和隔离样本验证。导出结构可能改变；识别不到结构会明确报错。附件实体不保证包含，当前元数据索引中的缺失附件需要用户补充原文件，不按模糊文件名自动配对。
4. Office 是简化 XML 内容预览，不提供 Word 完整排版、Excel 公式重算或 PPT 幻灯片保真渲染；外部默认应用可打开。XLSX 共享字符串/工作表原始值不保证直接还原为美化网格。
5. 扫描 PDF 无 OCR，密码保护文档需要用户自行解锁后导入。未知格式仅信息与外部打开。Markdown/代码使用轻量安全渲染；CSV 预览不等同完整电子表格编辑器。
6. 外部编辑通过受管理工作副本和用户主动“检查外部编辑”识别；当前不持续实时扫描所有工作副本。不登记的编辑不属于正式版本，也不随默认正式成果备份。
7. ZIP 不支持加密、多卷、ZIP64、超多成员、异常压缩比与不安全路径；对部分特殊文件名限制，安全优先。不递归展开嵌套压缩包；RAR/7z 等仅登记和外部打开。
8. 目录监控采用低频稳定扫描，文件稳定两个连续扫描后登记；不是文件系统事件秒级同步。首次授权 Downloads 既有文件建立基线，只有后续变化待确认。大目录请拆分专用接收位置。
9. **真实 Ollama 模型推理/嵌入、DeepSeek 付费请求、交互式 Keychain 写入未联调。** 本机未配置可用模型或用户 API Key，未下载模型/未发起付费请求。代码、权限门禁、索引、RAG准备及失败回退已有隔离测试，不能冒充模型成功联调。
10. 本地向量为 SQLite 中的向量与余弦候选扫描，上限20,000片段；没有独立 ANN、交叉编码器重排、OCR或大型模型后台服务。万条性能结果只针对合成元数据查询，不包括长文向量或真实万文件吞吐。
11. DeepSeek 地址限官方 HTTPS（可选/v1），模型可配置，价格由用户核实填写；无自动价格抓取。请求失败不自动重试，以免重复费用；可主动重试。预算为保守本地估计，最终账单由服务商决定。
12. AI 任务状态在应用重启后不续跑，已运行请求留中断记录。取消不能撤回已经被第三方接收的内容。用户另行启动的 Ollama 不由 WorkVault 强行停止。
13. 备份是文件夹和 SHA清单，不带密码加密、数字签名或云备份。恢复只写新的独立目录；当前没有就地合并恢复。没有自动定时备份或自动更新。
14. 登录启动默认关闭，仅用户启用后写用户 LaunchAgent；没有在真实 OS重启/注销时测试。已测试应用退出再重启持久化，不能替代系统重启实测。
15. 构建 ARM64/macOS15，实测15.8.3；没有 Apple Developer证书或公证。未覆盖其他系统版本、所有外置SSD文件系统、突然断电与真实磁盘硬件故障。断盘状态和磁盘不足通过隔离场景验证。
16. 没有全局永久清空 blob 垃圾回收工具，默认保留回收站及历史版本，以降低误删风险。长期大量删除后磁盘占用可能不立即下降。
17. UI全局搜索基于数据库元数据；正文全文/语义检索只能覆盖用户手动建立的索引。文档页码只有可准确提取的PDF才提供，Office简化内容不捏造页码。
18. 批量导入取消会停止剩余文件；已在复制/校验的单个文件可能先完成安全提交。进度主要按完成文件数显示，不提供每个文件的逐字节百分比。ZIP 安全预检和展开完成后才得到完整批次文件数。
